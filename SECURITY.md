# Security policy

## Supported versions

Security fixes are made against the latest published PyWorldAtlas release and
the current `main` branch. Users should upgrade to the newest release before
reporting an issue that may already be resolved.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include
exploit details in a discussion or pull request.

Use GitHub's private vulnerability-reporting or security-advisory feature for
this repository when it is available. If private reporting is unavailable,
open a public issue that requests a private contact channel but contains no
vulnerability details. In the private report, include:

- the affected PyWorldAtlas and Python versions;
- the operating system and installation method;
- a concise description of the impact;
- the smallest safe reproduction you can provide; and
- whether the issue is already public elsewhere.

The maintainer will confirm receipt, assess the report, and coordinate a fix
and disclosure when appropriate. Please allow time for supported-version tests
and release validation before publishing details.

Factual data corrections, documentation errors, and ordinary package bugs are
not security vulnerabilities; use the repository's public issue forms for
those reports.
