# PyWorldAtlas place pack notices

Place packs contain derived, transformed data from the GeoNames gazetteer:
names, kinds, coordinates (rounded to about 110 m), population, and elevation,
plus counts of names in other languages used to order search results.

- **Places and names:** GeoNames, licensed under CC BY 4.0.
  This product includes data created by GeoNames users and made available from
  https://www.geonames.org/. https://creativecommons.org/licenses/by/4.0/

Places are not suitable for navigation. The full source manifest, checksums,
and transformation code are published in the PyWorldAtlas repository:
https://github.com/jcari-dev/pyworldatlas
